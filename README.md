# Motiv-Buy

Motivational shopping bot built with NestJS and Telegram Bot API.

## Structure

- `monorepo/` - Main application code and libraries
- `docs/` - Project documentation

## Development

All development work should be done in the `monorepo/` directory.

```bash
cd monorepo
pnpm install
pnpm run build
pnpm run test
```
